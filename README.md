# frontend-ai-capstone

This repository contains my capstone project for FlyRank AI's Week 1 (FE-01) assignment.

## Tech Stack

- Node.js (LTS)
- Git
- Cursor

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS)
- [Git](https://git-scm.com/)

### Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/cmdjoel/frontend-ai-capstone.git
   cd frontend-ai-capstone
   ```

2. Verify Node.js is installed:

   ```bash
   node --version
   ```
